# Fitlog - Workout Tracker

## Short Description
Fitlog is a fast and simple web app built to help you plan and track your daily exercises. You can look through a library of workouts, save your favorites, and manage a focused daily routine. 

## Technologies Used
* **Next.js** & **React** (for building the user interface)
* **Tailwind CSS** (for styling and dark mode)
* **Next.js** & **React** (for building the user interface)
* **TypeScript** (for clean and safe code)
* **Context API** (for managing state)
* **Local Storage** (for saving user data in the browser)

## 5 Key Features
1. **Daily Plan Limit:** Add up to five workouts to your "Today's Plan" to keep your goals realistic and focused.
2. **Save Favorites:** Keep a separate list of your favorite exercises so you can find them easily later.
3. **Smart Sorting:** Organize your workout lists by time (duration), calories burned, or user rating.
4. **Track Progress:** Click "Mark as Done" to finish a workout and clear it from your daily list.
5. **Instant Alerts:** Get clear and helpful pop-up messages when you add, remove, or complete a workout.
